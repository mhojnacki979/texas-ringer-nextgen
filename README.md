# Texas Ringer: The Next Gen

> ⚠️ **Retired / archived (2026-08-27).** This standalone build has been
> superseded. The live 2026 Texas Ringer: The Next Gen scoring runs on the main
> Texas Ringer site — **https://texasringer.eyesonscore.com** (repo
> [`mhojnacki979/texas-ringer`](https://github.com/mhojnacki979/texas-ringer)).
> This repo is kept read-only as a backup; do not deploy from it.

Public results site for the **2026 Texas Ringer: The Next Gen** archery
tournament — single-elimination brackets, champions, and qualification
standings, powered by [Eyes on Score](https://www.eyesonscore.com).

Static Next.js site (no database). Event results are pulled from the Eyes on
Score API into static JSON at build time; a `/live` page reads the API directly
in the browser while the event is running.

## How it works

- **`src/data/events/<year>.json`** — baked results for each event, read by the
  site. Generated by the sync script below. `comingSoon: true` shows a
  "Scores coming soon!" state before the event has scores.
- **`scripts/sync-events.ts`** (`pnpm sync:events`) — pulls qualification +
  bracket data from the EOS API (`tournament_group_bracket_layout`, the
  authoritative single-elimination pairing tree) into the JSON above. The
  champion is the winner of the final round's gold match, **not** the highest
  raw score.
- **`src/lib/live-config.ts`** — points the `/live` page at the running
  tournament; `null` between events.

The Next Gen tournament (EOS id `d2hHaFVkWEFKNDdoSTRQNWVwQ0pxZz09`) shoots
**Aug 29, 2026**. Until then the site shows the coming-soon state.

## Usage

```bash
pnpm install
pnpm dev            # http://localhost:3000
pnpm typecheck
pnpm test
pnpm build          # static export → ./out

pnpm sync:events    # pull latest EOS results into src/data/events/*.json
                    # (needs EOS_API_TOKEN in .env — see .env.example)
```

### Running an event

1. **Go live:** in `src/lib/live-config.ts`, set `LIVE_TOURNAMENT` to
   `{ id: 'd2hHaFVkWEFKNDdoSTRQNWVwQ0pxZz09', name: '2026 Texas Ringer The Next Gen' }`
   and push. The `/live` page auto-refreshes from the EOS API.
2. **After the event:** run `pnpm sync:events` to bake the final
   qualification + brackets into `src/data/events/2026.json` (the sync
   overwrites the file and clears the coming-soon state), set
   `LIVE_TOURNAMENT` back to `null`, commit, and push.

## Deploy

GitHub Pages via `.github/workflows/deploy.yml` — builds `out/` and publishes on
every push to `main`. `basePath` defaults to `/texas-ringer-nextgen` (the
project URL); set `basePath = ''` in `next.config.mjs` and add `public/CNAME`
for a custom domain.

## Layout

```
app/                Next.js 15 app router (home, /events/[year], /live, 404)
src/data/           event JSON + the read contract (events.ts)
src/lib/            EOS client (eos.ts), live config, asset() base-path helper
scripts/            EOS sync (sync-events.ts)
public/brand/       Ringer brand kit (wordmark, antlers, mark)
```
